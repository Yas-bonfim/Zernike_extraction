# Zernike Coefficients Extractor
This Python script extracts and estimates Zernike polynomial coefficients from a 2D color image representing an optical phase map. It maps the image colors back to numerical phase values, detects the pupil area, and performs a least-squares fit to calculate the coefficients according to the OSA/ANSI standard.


## Features
* Automatic Pupil Detection: Isolates the region of interest based on brightness against a dark background.

* Reverse Color Mapping (LUT): Uses KD-trees (cKDTree) to convert RGB pixel colors back into continuous phase values based on a specified colormap (cmap).

* Zernike Basis Generation: Calculates radial polynomials and Zernike functions following the OSA/ANSI standardization.

* Least-Squares Fitting: Finds the coefficients that best reconstruct the original phase.

* Visualization and Export: Plots comparative maps (extracted phase, reconstructed phase, and residual error) and exports the calculated coefficients to a CSV file.

## Prerequisites
make sure you have Python 3.14 installed. You will need the following libraries:
```
pip install numpy pandas matplotlib pillow scipy
```  

## Configuration
Before running the script, adjust the variables in the CONFIGURACOES section at the top of the code according to your target image:

* IMAGE_PATH: Path to the phase map image (e.g., "Z4_amp-0.01.png").

* N_COEFFICIENTS: Number of Zernike modes to extract (e.g., 15 for radial order up to $n=4$).

* PHASE_MIN / PHASE_MAX: Phase boundaries represented by the extreme colors on your original image's colorbar.

* CMAP_NAME: Name of the matplotlib colormap used to generate the original image (e.g., "turbo", "jet", "viridis").

* PUPIL_CENTER / PUPIL_RADIUS: Leave as None for automatic detection, or set numerical values (in pixels) if the image has a noisy background that hinders the auto-detection.

  ##How To Use

1. Place your phase map image in the same directory as the script (or update IMAGE_PATH accordingly).

2. Edit the configurations mentioned above, ensuring that the CMAP_NAME and phase limits (PHASE_MIN, PHASE_MAX) match the exact scale of your original image.

3. Run the script:
   ```
   python main.py
   ```

## Generated Outputs
1. Terminal Logs:

  * Image dimensions.

  * Detected pupil center and radius.

  * Residual RMS (Root Mean Square) error value.

2. CSV File:
  *  zernike_coefficients.csv: A table containing the OSA indices, $n$ and $m$ values, and the calculated   coefficient (in radians) for each Zernike mode.

3. Plots (Matplotlib):
   * Extracted Phase: The numerical phase map reconstructed directly from the pixels' colors.
  
   * Reconstructed Phase: The phase map generated by the sum of the Zernike polynomials multiplied by the estimated coefficients.
  
   * Residual Error (Erro residual): The spatial difference between the extracted phase and the reconstructed phase.
